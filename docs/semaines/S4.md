## À comprendre

1. **Pourquoi une table de points pour Delta(S)** : la vue graphique d'Odoo agrège des enregistrements, elle ne trace pas une fonction ; le bouton crée 21 points (spot de 50 % à 150 % du strike).
2. **Deux variantes du LSTM** : V0 (guide) prédit la volatilité du lendemain, qui partage 4 rendements sur 5 avec l'entrée, donc la persistance est très forte ; V1 prédit les 5 jours suivants **sans chevauchement**.
3. **Références** : persistance (demain comme aujourd'hui), EWMA λ = 0,94 (RiskMetrics), GARCH(1,1) estimé sur le train seul. **Métriques** : RMSE et QLIKE, sur le jeu de test.
4. **Honnêteté** : si GARCH ou l'EWMA battent le LSTM, on le présente tel quel. Sur données simulées par GARCH, GARCH gagne logiquement ; le tableau à présenter est celui des données réelles.
5. **Export** : Odoo n'a pas TensorFlow ; les poids vont dans `models/lstm_vol.npz` et `src/ml.py` refait le calcul en NumPy, vérifié identique à Keras par un test.
6. **Gantt réalisé** : barres grises = prévu, en couleur = réalisé ; les dates réelles ne se modifient jamais après coup.
