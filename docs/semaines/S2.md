## À comprendre (Assia présente, tout le monde doit savoir le dire)

1. **Rendement log** `r_t = ln(S_t/S_{t−1})` ; **volatilité historique** `σ = écart-type(r_t) × √252` : 252 jours de bourse par an.
2. **Black-Scholes** : `C = S·N(d1) − K·e^(−rT)·N(d2)` ; cas de référence (S = K = 100, T = 1, r = 5 %, σ = 20 %) : call 10,4506, put 5,5735.
3. **Delta** = N(d1) = 0,6368 : nombre d'actions pour couvrir le call. **Gamma** maximal à la monnaie.
4. **Trois preuves que le code est juste** : valeur de référence, différences finies (écart < 1e-4), parité call-put (écart < 1e-10).
5. **`r` du cas AAPL est une hypothèse** (4 %) : à remplacer par un taux sourcé avant de le présenter.

**Questions probables** : pourquoi √252 et pas √365 ? Pourquoi le Delta n'est-il pas la probabilité d'exercice (c'est N(d2)) ? Que montre la courbe du Gamma ?
