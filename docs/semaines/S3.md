## À comprendre

1. **`_inherit = "cours.option"`** ajoute des colonnes à la table du TP 0 sans la recopier ; on garde ses noms (`S0`, `K`, `T`, `r`, `sigma`, `type`).
2. **Champ calculé stocké** : `@api.depends(...)` dit quand recalculer, `store=True` l'écrit en base (indispensable pour trier, grouper, tracer).
3. **Le calcul reste dans `src/pricing.py`** : Odoo l'importe (`PYTHONPATH=/mnt/finance_src`), donc les 25 tests pytest garantissent aussi Odoo.
4. **Jamais d'exception dans un champ calculé** : une entrée invalide donne 0, la contrainte du TP 0 refuse S0 ≤ 0.
5. **Delta du portefeuille** = somme des Delta × quantité, avec un signe négatif pour les positions vendeuses.
6. **Données du LSTM (Hiba)** : la variante V1 prédit la volatilité des 5 jours **suivants** à partir des 30 derniers rendements, sans chevauchement ; références : persistance, EWMA (λ = 0,94), GARCH(1,1) ; découpage 70/15/15 chronologique.
