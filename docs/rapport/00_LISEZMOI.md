# Rapport final — mode d'emploi

Une section par fichier, une section par casquette (S5 à S7), pour que chacun commite la sienne.
Assemblage en S7 : `pandoc docs/rapport/0[1-7]_*.md -o docs/rapport/rapport_final.docx` (ou PDF), puis mise en page.
Règle : tout chiffre vient d'une sortie exécutée (notebook, test, Odoo), jamais de mémoire. Les emplacements `⟦…⟧` sont à remplir avec ces sorties.
